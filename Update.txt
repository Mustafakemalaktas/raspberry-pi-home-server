[FIX] Server did not boot back by itself after a short power cut or flicker.
      The Pi stayed off and had to be restarted by hand.
      Cause: bootloader (EEPROM) power settings.
      Solution: updated the firmware and set the following in the
      bootloader config (sudo -E rpi-eeprom-config --edit):
          POWER_OFF_ON_HALT=0
          WAKE_ON_GPIO=1
      Result: the server now starts automatically when power returns.
